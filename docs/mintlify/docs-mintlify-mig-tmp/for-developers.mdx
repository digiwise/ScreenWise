ScreenWise exposes locally recorded screen, accessibility, OCR, audio, meeting,
and input data through an authenticated API on `127.0.0.1:3030`.

## first request

```powershell
$token = screenpipe auth token --data-dir <recorder-data-directory>
curl.exe "http://127.0.0.1:3030/search?q=error&limit=10" `
  -H "Authorization: Bearer $token"
```

Use [API recipes](/api-recipes) for search, frames, meetings, speakers,
retention, and local deletion workflows.

## MCP

The repository includes a separate MCP package that calls the same loopback
API. Build or install a reviewed version explicitly, pass
`SCREENPIPE_LOCAL_API_KEY`, and configure your chosen local MCP host manually.
ScreenWise does not download the package or edit third-party settings. See
[MCP server setup](/mcp-server).

## local AI

ScreenWise's retained chat path is Pi with Ollama at the fixed loopback endpoint
`127.0.0.1:11434`. Hosted model providers and arbitrary remote endpoints are not
supported. See [Ollama](/ollama).

## security

Keep bearer authentication enabled. Recorded data can contain sensitive screen
and audio content, so grant API or MCP access only to trusted local processes.
