ScreenWise chat supports Ollama only. It uses the fixed loopback service at
`http://127.0.0.1:11434`; there is no arbitrary model endpoint, hosted AI
gateway, or provider API-key setting.

## provision Ollama explicitly

ScreenWise never downloads Ollama or an Ollama model. Install Ollama using your
organization's approved process, verify the installer, and pull the models you
intend to use before enabling local chat.

For example, after Ollama is installed:

```powershell
ollama pull qwen3:4b
ollama serve
```

Model acquisition is an explicit administrator or user action, not an
application startup side effect.

## use it in ScreenWise

1. Confirm Ollama is running locally.
2. Open the ScreenWise chat or timeline.
3. Select the native Ollama preset.
4. Choose a model already installed in Ollama.

ScreenWise asks the local Ollama service for its installed model list and sends
chat requests only to that loopback service.

## troubleshoot

Check that the loopback service is reachable:

```powershell
curl.exe http://127.0.0.1:11434/api/tags
```

If a model is missing, provision it outside ScreenWise and restart the local
Ollama service. If chat reports that Pi is missing, provision the reviewed,
pinned-version Pi runtime under the ScreenWise data directory; ScreenWise does
not install or repair it from the Internet.
