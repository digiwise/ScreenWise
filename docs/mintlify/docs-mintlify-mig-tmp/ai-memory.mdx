ScreenWise stores searchable screen and audio records locally and exposes them
through an authenticated loopback API. Optional AI analysis stays local through
the native Ollama preset.

## local Ollama chat

Provision Pi and Ollama before enabling chat. ScreenWise uses only
`http://127.0.0.1:11434` and does not accept a hosted or arbitrary model
endpoint. See [Ollama](/ollama).

## local API and MCP

Local programs can query recent activity directly:

```powershell
curl.exe "http://127.0.0.1:3030/search?limit=20" `
  -H "Authorization: Bearer <local-token>"
```

An explicitly provisioned MCP package can expose the same authenticated API to
a trusted local MCP host. ScreenWise does not install, configure, or update that
package. See [MCP server setup](/mcp-server).

## privacy controls

- capture exclusions apply before local persistence
- deterministic regex redaction is always available
- semantic ONNX redaction activates only after verified models are provisioned
- no hosted AI, cloud transcription, archive/sync, or service connector is used
