ScreenWise is a Windows-first personal activity recorder. It captures screen
and accessibility text, applies OCR where needed, records selected local audio,
and stores searchable results in a local SQLite database.

## retained capabilities

- Windows Graphics Capture with multi-monitor support
- Windows UI Automation and local OCR
- local microphone and system-audio capture
- local speech transcription and meeting privacy controls
- authenticated loopback API and local SQLite search
- deterministic regex redaction and explicitly provisioned ONNX PII models
- optional local chat through an explicitly provisioned Pi runtime and Ollama

ScreenWise has no product account, subscription, cloud sync, hosted AI gateway,
pipe store, or service-connection system. The application does not download
runtime tools or models. Provision required components separately and verify
them before enabling the dependent feature.
